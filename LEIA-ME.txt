MUSICALIZANDO NO CÉU — SINCRONIZAÇÃO COM GOOGLE SHEETS

1. GOOGLE APPS SCRIPT
- Abra a planilha e confirme que a aba se chama exatamente: Planilha 2
- Abra Extensões > Apps Script.
- Substitua o código pelo conteúdo de Google_Apps_Script.gs.
- Salve.
- Em Implantar > Gerenciar implantações, edite a implantação do Web App para usar a nova versão.
- Execute como: você.
- Acesso: qualquer pessoa.
- Se for uma implantação nova, copie a URL /exec e coloque-a em utils.py na variável URL_GOOGLE_SHEETS.
- O API_TOKEN deve ser exatamente igual nos dois arquivos.

2. ESTRUTURA DA PLANILHA
- Os IDs ficam na linha 2.
- Os IDs começam na coluna C.
- Os rótulos (Usuário, Idade, Série, Pergunta 1_1 etc.) ficam na coluna B.
- Para cada pergunta, as quatro linhas devem continuar nesta ordem:
  Pergunta
  Resposta
  Correta
  Tempo

3. PROGRAMA
Substitua main.py e utils.py pelos arquivos deste pacote.
assets.py e render.py podem permanecer como estavam; foram incluídos apenas para facilitar a substituição conjunta.

4. DADOS LOCAIS
O dados.json deste pacote começa como uma lista vazia:
[]
Cada computador mantém sua cópia local. O ID oficial é gerado centralmente pelo Google Sheets.

5. FUNCIONAMENTO
Ao clicar em Começar:
- o jogo solicita um ID central;
- o Google Apps Script usa LockService para evitar IDs duplicados;
- o ID é colocado na próxima coluna da Planilha 2;
- Usuário, Idade e Série são enviados para essa coluna;
- as respostas e os tempos são enviados durante o jogo;
- ao chegar ao relatório, todos os dados locais do participante são reenviados para garantir uma segunda tentativa de sincronização.

6. IMPORTANTE
O campo Usuário continua existindo e é armazenado normalmente, mas não é usado como identificador.
O tempo de resposta é enviado em segundos, com duas casas decimais.
